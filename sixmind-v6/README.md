# SixMind V6 — Site Comercial Cinematográfico

V6 construída em paralelo à V4.5, preservando a versão anterior.

## Fases incluídas

- F0 — isolamento e estrutura segura
- F1 — arquitetura comercial completa
- F2 — demo sanitizada com dados 100% fictícios
- F3 — jornada cinematográfica ampliada
- F4 — caos operacional / dores
- F5 — Antes x Depois

## Rodar localmente

```bash
python -m http.server 8080
```

Abra `http://localhost:8080` dentro desta pasta ou use Live Server.
